# Данные для расчёта доставки воды по Чирчику

Первый результат — объём за сутки или месяц на входе в конкретный оросительный канал Ташкентской области. Объём питьевой воды в городе потребует отдельного баланса водоканала. Бозсу у ГЭС № 6 можно использовать как промежуточную точку проверки.

## Расчёт

1. Запас воды в снегу = сумма по ячейкам SWE в мм × площадь пересечения с водосбором в км² × 1 000. Если SWE уже усреднён по площади ячейки, доля снега повторно не умножается.
2. На прогнозный период считаем таяние и речной приток с учётом дождя, ледникового вклада и времени добегания. Калибруем по фактическим расходам.
3. Берём сброс из Чарвака по данным оператора или считаем по балансу. Сброс = приток − изменение запаса − потери за тот же период.
4. Двигаемся по схеме участков. Прибавляем боковые притоки и возвраты, вычитаем подтверждённые чистые отборы и потери. Объём на входе в канал считаем по среднему расходу и длительности. Один м³/с за сутки равен 86 400 м³.
5. Gemma объясняет готовый результат, период, источники и пропуски. При отсутствии расхода или проверенного коэффициента доставки на последнем участке показываем последнюю измеренную точку.

## Получение и хранение

Источники читаем по API или из официальных выгрузок. Храним на сервере обрезанные кадры и значения с датой наблюдения, временем загрузки и источником. В приложении выдаём небольшую сводку через API. Большой архив для обучения остаётся вне веб-сборки.

Локальный Snow2Crop при запуске и каждые три часа проверяет последние семь дат по GIBS и POWER. В карте у снимка и погоды свои даты. Если свежий кадр облачный, он виден в карточке с предупреждением. Проверенная подборка безоблачных кадров доступна отдельно. При переносе на постоянно включённый сервер этот же сбор можно запускать по расписанию независимо от браузера.

## Дополнительные источники для проверки поля

- [Казгидромет](https://www.kazhydromet.kz/ru/gidrologiya/konsultativnyy-prognoz-pogody-na-sezon) публикует замеры сброса Чарвака и расхода в устье Бозсу. Они дают региональный ориентир. Расход на входе в оросительный канал нужен отдельно.
- [Районная служба подачи воды Паркента](https://gov.uz/oz/suvobekt/news/view/127891) — подтверждённая точка для пилота. Для проверки нужны выгрузка по водозаборам и фактической подаче из [Suv hisobi](https://gov.uz/oz/suvchi/news/view/14991), привязка поля к каналу и период измерений. Публичный API с данными по отдельным участкам не подтверждён.
- [NASA SMAP L4](https://developers.google.com/earth-engine/datasets/catalog/NASA_SMAP_SPL4SMGP_008) содержит оценки влажности верхнего слоя и зоны корней на сетке 9 км. Подходит для регионального фона, для проверки полива отдельного поля нужны местные замеры.
- [FAO WaPOR](https://www.fao.org/in-action/remote-sensing-for-water-productivity/wapor-data-access/en) предоставляет данные о фактическом испарении через API. Перед использованием нужно подтвердить покрытие и детализацию для пилотного участка. Испарение само по себе не показывает объём воды из канала.
